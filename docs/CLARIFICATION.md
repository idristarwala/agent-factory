# Defining a goal in chat

In Factory chat, send **Create a factory to…** followed by what you want to accomplish. An empty goal prompts for its objective. You can attach documents, images and GitHub sources so the steward can draft acceptance criteria with citations. Review a draft, request changes or approve the version you want to use. [Attachment workflow](../README.md#goal-chat-attachments)

To run the design, select the factory and supply compatible records or a versioned mapping in Goal builder. The mapping preview lets you check record identity and field types before starting. [Source mapping](MAPPING.md) · [Chat API](API.md#chat-and-feedback)
